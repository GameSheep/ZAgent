# Native Obsidian utility

Mode: Operate. Inherit Obsidian's existing visual world, fonts, theme, menu behavior, modal focus handling, accent, and spacing. No separate product website or visual identity.

Composer hierarchy: current note → available Agent selection → compact quick-task buttons → instruction textarea → expandable full-prompt preview → launch action. Use Obsidian theme tokens (`--background-primary`, `--background-secondary`, `--text-normal`, `--text-muted`, `--interactive-accent`, `--background-modifier-border`) and native button styles. File paths use `--font-monospace`; ordinary text uses the app font. Show status with text as well as color. Keep focus visible, keyboard launch via Ctrl/Cmd+Enter, and errors inside the modal. Narrow windows stack footer controls.
