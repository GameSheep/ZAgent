# ZAgent 0.1.0

Launch a local AI agent from the current Obsidian Markdown note. Compose the task in Obsidian, then continue in the agent's native interactive terminal with the note's absolute path included.

- Entry points: note menu, file/editor context menus, ribbon, and command palette.
- Detect Claude Code, Codex, Gemini CLI, and OpenCode; configure another CLI if needed.
- Quick tasks: improve writing, adjust Markdown layout, proofread, and summarize.
- Save the open Markdown editor before passing the file path to the agent.
- Preserve Unicode, quotes, and multiline prompts through a native Windows console.

Desktop only. Automated tests and Windows console TTY checks pass. End-to-end use in a real Obsidian host and macOS/Linux terminal launch have not yet been verified.

ZAgent is not yet listed in the Obsidian Community directory. For manual installation, extract `zagent-0.1.0.zip` and copy its `zagent` folder into your vault's `.obsidian/plugins/`, then enable ZAgent. The three standalone assets are also included for Obsidian distribution.

The plugin uses your existing Agent installation and login. It does not include API keys or bypass the Agent's permission checks.
